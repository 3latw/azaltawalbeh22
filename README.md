## الملفات

- `index.html`: الصفحة الرئيسية وجميع عناصر الواجب المطلوبة.
- `contact.html`: صفحة تواصل منفصلة بأربعة حقول.

- `course.css`: تنسيق نسخة الواجب والتجاوب مع أحجام الشاشات.
- `app.js`: التحقق من الحقول وإظهار alert عند النجاح.
- `assets/`: الصورة المقدمة من الطالب، الخطوط، والأيقونة.
